# Kuis UTS Manajemen Bisnis Keluarga

Latihan soal pilihan ganda untuk UTS Manajemen Bisnis Keluarga: **105 soal dari 7 topik** (15 soal per topik).
Klik salah satu jawaban, lalu kunci jawaban dan pembahasannya langsung muncul.

**Buka kuisnya:** https://dhafink.github.io/uji-coba-soal-bisnis-keluarga/

| Topik | Materi |
|---|---|
| 1 | Genogram |
| 2 | 3-Circle Model |
| 3 | Tata Kelola Bisnis Keluarga (family governance) |
| 4 | Tata Kelola Perusahaan Keluarga (corporate governance) |
| 5 | Profesionalisme |
| 6 | Profesional yang Bekerja di Perusahaan Keluarga |
| 7 | Kepemimpinan dalam Bisnis Keluarga |

## Cara pakai
1. Buka link website kuisnya.
2. Pilih topik, jumlah soal, dan apakah urutan soal mau diacak.
3. Klik jawaban. Jawaban yang benar akan berwarna hijau, pilihan yang salah berwarna merah, lalu pembahasannya muncul.
4. Di akhir sesi ada skor per topik dan tombol **Ulangi yang salah**.

Progres dan riwayat jawaban tersimpan di browser masing-masing. Tidak perlu akun.
Shortcut keyboard: `1`–`4` atau `A`–`D` untuk memilih jawaban, `Enter` untuk lanjut.

## Catatan materi
Soal disusun dari literatur standar bisnis keluarga (Tagiuri & Davis, Gersick dkk., McGoldrick & Gerson,
Pedoman GCG KNKG, UU No. 40/2007 tentang PT, Sonnenfeld, Handler, Lansberg, dll.) ditambah studi kasus Keluarga Santoso
(Tugas 1). Soal-soal ini adalah bahan latihan, bukan bocoran soal ujian. Tetap cocokkan dengan slide dan catatan kuliah.

## Menjalankan di komputer sendiri
Double-click `jalankan.bat` (butuh Python), lalu buka http://localhost:8765.
Bisa juga dengan langsung membuka `index.html` di browser.

Bank soal ada di folder `data/` (satu file per topik). Untuk mengecek validitas bank soal setelah mengedit, jalankan `node cek_soal.js`.
